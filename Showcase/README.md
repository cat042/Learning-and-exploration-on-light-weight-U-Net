# Polyp Segmentation Study Showcase

This directory is a cleaned, public-facing version of my summer exploration project on polyp segmentation with PyTorch.

The project has three goals:

- implement a standard UNet baseline
- explore custom lightweight grouped-channel variants
- record experimental results honestly, including negative results

This is a **runnable research-style project**, not just a static code dump.  
However, to keep the repository suitable for GitHub, the raw datasets and trained checkpoints are **not included** in this showcase folder.

## What this project contains

- training code
- evaluation code
- prediction code
- model definitions
- experiment summaries
- short notes about architecture design and reflections

## Can this project run?

Yes.

The code in [src/](/D:/sprograms/WhiteNights/ThirdNight/experiments/github-showcase/src) is runnable, but there are two important conditions:

1. you need to install the Python dependencies
2. you need to prepare the dataset locally before training or evaluation

For evaluation and prediction, you also need a trained checkpoint generated by your own run, because pretrained weights are not included in this showcase.

## Environment

Recommended:

- Python 3.10+ or 3.11+
- PyTorch installed in your environment
- Windows PowerShell or a normal terminal

Install dependencies:

```bash
pip install -r requirements.txt
```

## How to run

Open a terminal in [github-showcase/](/D:/sprograms/WhiteNights/ThirdNight/experiments/github-showcase).

### 1. Train the main custom model

```bash
python src/train.py --model premier_model
```

This will create a run directory such as:

```text
runs/premier_model/seed_1337/
```

and save a checkpoint like:

```text
runs/premier_model/seed_1337/best_model.pt
```

### 2. Train the baseline model

```bash
python src/train.py --model baseline_unet --output-dir runs/baseline_unet
```

### 3. Evaluate a checkpoint

After training, evaluate the generated checkpoint:

```bash
python src/evaluate.py --checkpoint runs/premier_model/seed_1337/best_model.pt
```

You can also evaluate a baseline checkpoint:

```bash
python src/evaluate.py --checkpoint runs/baseline_unet/seed_1337/best_model.pt
```

### 4. Predict masks for images

```bash
python src/predict.py --checkpoint runs/premier_model/seed_1337/best_model.pt --input path\to\images
```

If `--input` points to a folder, the script will generate one predicted mask per image in the output directory.

## What each script does

- `src/train.py`
  - trains one selected model
  - supports `baseline_unet`, `basic_model`, and `premier_model`
  - saves training history, config, metrics, and the best checkpoint

- `src/evaluate.py`
  - evaluates one or more checkpoints on all configured test datasets
  - prints per-dataset Dice and IoU metrics

- `src/predict.py`
  - loads a trained checkpoint
  - predicts segmentation masks for one image or a folder of images

## Quick command reference

## What is intentionally excluded

To keep this folder suitable for a public GitHub repository, it does **not** include:

- raw image datasets
- full training artifacts
- pretrained `.pt` checkpoints
- temporary caches

These are excluded on purpose, not missing by mistake.
